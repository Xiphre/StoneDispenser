# Changelog

## 0.4.0 (unreleased)

- Key binding under Esc > Key Bindings > AddOns > TradeStone: one key creates and trades a Healthstone, same as clicking the button.
- The button (and key) only acts while a trade window is open.

## 0.3.0

- The button sits next to Blizzard's Trade button and matches its style; the label "Trade Healthstone" is now "Trade Stone".
- The button is drawn on the top layer so UI skins that overlay the trade window (such as EllesmereUI) no longer hide it.

## 0.2.0

- One button replaces the two: it trades your Healthstone, or creates one and puts it into the trade when the cast finishes.

## 0.1.0

- First version: Create Healthstone and Trade Healthstone buttons on the trade window, warlocks only.
- `/ts` debug command.
